# Voice（英語の文体ガイド）

## 基本

- **一人称 "I"**。日本国内から、日本語の一次資料を読んで書いている視点。"From where I sit in Japan…" は使いすぎない（1号1回まで）。
- **短い段落**：1段落2〜4文。1文は25語以内を目安。
- **具体的な数字**：割合だけでなく実数・期間・前年比を添える。出典はリンクで。
- **冒頭2文で言い切る**：「今週の一番大事なこと」と「だからどうなるか」。
- **誇張なし**：*huge, game-changer, skyrocketing, crisis*（政府用語の引用を除く）、感嘆符は使わない。
- **確度を言葉で示す**：*The data shows / I think / I'm not sure yet* を使い分ける。推測は推測と書く。

## 用語ルール

| 日本語 | 英語での書き方 |
|---|---|
| 国土交通省 | MLIT (the Ministry of Land, Infrastructure, Transport and Tourism) — 初出のみフル |
| 特定技能 | Specified Skilled Worker (SSW) |
| 育成就労 | Employment for Skill Development (ESD) — 初出に "replacing the Technical Intern Training Program" |
| 建設機械 | construction equipment / machines（"heavy machinery" は和製寄りなので避ける） |
| ICT施工 | ICT-enabled construction (machine control/guidance, 3D data) |
| 国土強靱化 | national resilience (infrastructure hardening) program |
| 年度 | Japan's fiscal year (April–March)。"FY2026" 初出で説明 |
| 億円・兆円 | ¥ billion / ¥ trillion に換算。USD換算は換算日を明記（"≈ $X at ¥Y/$"） |

## 構成の型（週次ブリーフ）

1. **The one thing**（2文）
2. **3 moves this week**（各100〜200語：What happened → Why it matters for you → What I'd watch）
3. **One number**（今週の数字1つ＋一言）
4. **Paid link**（深掘り号への自然な導線1行）

## やらないこと

- 日本語記事の全文翻訳・長い引用（引用は1文まで、出典付き）
- 和製英語（*after service, plant (=工場の意味以外), know-how を多用*）、直訳調（*It can be said that…*）
- 勤務先・取引先に関する記述、匿名でも特定できる体験談
